# Ambxst Mods (`ambxstMod`)

A collection of mods for [Ambxst](https://github.com/Axenide/Ambxst), a modular Wayland shell built with QuickShell and Qt/QML.

## Included Mods

### 1. [Ambxst YTD (`ambxst-ytd`)](./ambxst-ytd)
* **ID**: `mnojz.ambxstytd`
* **Description**: Download YouTube audio (`.mp3` to `~/Music`) and video (up to 4K `.mp4` to `~/Videos`) from an Ambxst bar popup or desktop `ytd:` links.
* **Features**: Live progress bar, cancellation, request queue, download history, and standalone icon tinting.

### 2. [Rubber Band Selection Overlay (`rubberBandSelectionOverlay`)](./rubberBandSelectionOverlay)
* **ID**: `mnojz.dragoverlay`
* **Description**: Ambxst mod for creating a rubber band selection overlay for spawning terminals or designated windows over the desktop.
* **Features**: Wayland overlay layer shell, multi-monitor support, configurable selection fill and border colors, border width, and corner radius via Ambxst mod settings.

### 3. [KDE Connect Helper (`kde-connect-helper`)](./kde-connect-helper)
* **ID**: `mnojz.kde-connect-helper`
* **Description**: Status bar control and actions for paired KDE Connect devices.
* **Features**: Device status, battery levels, ping/ring actions, file/text sharing via desktop portal, and user autostart controls.
